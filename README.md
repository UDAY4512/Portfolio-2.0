## ✦ About the Project

Built with a modern frontend stack, it features a dark editorial visual direction, thoughtful animations, responsive layouts, and a simple way for visitors and recruiters to get in touch.

## ✦ Getting Started

Want to run the project locally? Follow these steps.

### Prerequisites

- Node.js
- npm
- Git

### 1. Clone the repository

```bash
git clone https://github.com/UDAY4512/Portfolio-2.0.git
```

### 2. Navigate to the project

```bash
cd Portfolio-2.0
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

Create a `.env.local` file in the project root:

```env
VITE_WEB3FORMS_ACCESS_KEY=your_web3forms_access_key
```

Replace the placeholder with your own Web3Forms access key.

### 5. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal.

### 6. Build for production

```bash
npm run build
```

## ✦ Contact Form Configuration

The portfolio uses [Web3Forms](https://web3forms.com/) to handle contact form submissions.

To configure it:

1. Create an account on Web3Forms.
2. Generate an access key.
3. Add it to `.env.local` using the variable shown above.
4. Restart the development server.

**Note:** Keep `.env.local` out of Git commits. The `.gitignore` file excludes local environment files.

For Vercel deployment, configure `VITE_WEB3FORMS_ACCESS_KEY` in the project's Environment Variables.
